**DailyFlow** is a sleek, black-themed daily planner and to-do list web application. Designed for daily productivity, it allows users to quickly plan out their day when they wake up, track daily progress, and stay focused.

---

## 🌟 Key Features

- 📅 **Today's Live Date Header**: Displays the current weekday and date automatically.
- ⚡ **1-Click Quick Routine Chips**: Add common daily tasks (*Exercise, Reading, Work/Study, Meditation, Groceries*) with a single tap.
- ✍️ **Instant Daily Task Creation**: Type your custom tasks for the day with an optional ⭐ *Important* priority badge.
- 📊 **Daily Progress Bar**: Shows live completion metrics and progress percentages for today's tasks.
- 🖤 **Sleek Pure-Black OLED Theme**: High contrast dark theme with smooth checkmark animations.
- ☀️ **Start New Day Button**: Easily clear completed tasks when starting a fresh morning.
- 💾 **Local Storage Memory**: All tasks remain saved safely in your browser.

---

## 🚀 How to Run Locally

1. Open the project folder.
2. Double-click **`index.html`** to launch it in your browser.

---

## 🌐 Deploy Live to GitHub Pages

1. Upload the files (`index.html`, `styles.css`, `app.js`, `README.md`) to your GitHub repository.
2. Go to **Settings** $\rightarrow$ **Pages** in your repository.
3. Select `main` branch and click **Save**.
